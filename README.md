# MSPM0

Texas Instruments MSPM0 test board, used to test and evaluate the microcontroller's capabilities for future projects.

## Hardware overview

- **MCU:** TI MSPM0G3507 (ARM Cortex-M0+, 80 MHz, 128 kB flash, 32 kB SRAM)
- **Clock source:** 8 MHz external crystal
- **Motion sensing:** ST LIS2DH 3-axis accelerometer
- **USB-C:** USB 2.0 receptacle with USBLC6-2SC6 ESD protection on the data lines
- **Power:** SPX3819 LDO regulator, 3.3V rail
- **Debug:** SWDIO/SWCLK broken out for Serial Wire Debug
